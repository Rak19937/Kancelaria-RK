RK KANCELARIA 0.14.0 — DESKTOP & DOCUMENTS

Najważniejsze zmiany:
- nowy domyślny Desktop: PySide6 + Qt WebEngine we własnym oknie programu;
  nie uruchamia Edge/Chrome jako zwykłej przeglądarki;
- brak konsoli przy uruchamianiu przez `.pyw`, plik `.vbs` albo utworzony skrót; pliki `.bat` pozostają głównie do instalacji/diagnostyki;
- stabilny podgląd PDF strona po stronie przez PyMuPDF, z nawigacją i zoomem;
- obrazy JPG/PNG/GIF/WEBP/BMP/TIFF w aplikacji;
- podgląd tekstowy DOCX/TXT/RTF/CSV/MD;
- podgląd XLSX/XLSM przez openpyxl (wartości komórek, limity bezpieczeństwa);
- Otwórz w programie domyślnym i Otwórz folder dokumentu w trybie lokalnym;
- brakujący plik nie wywala aplikacji — ekran naprawy pozwala wskazać plik ponownie;
- bezpieczne ścieżki dokumentów i zapis pliku temp + atomic replace;
- połączenia SQLite są domykane i transakcyjne;
- manualny backup korzysta z SQLite backup API i uwzględnia WAL;
- backup przy każdym zamknięciu (10 ostatnich) + dotychczasowy backup dzienny (20);
- GUI przywracania backupu: restore jest weryfikowany i wykonywany przy następnym starcie;
- automatyczne recovery brakującej/uszkodzonej bazy z najnowszej poprawnej kopii,
  z zachowaniem uszkodzonego pliku w katalogu recovery;
- log błędów z prostą rotacją.

Nie zmieniono lokalizacji danych użytkownika:
%LOCALAPPDATA%\RK_KANCELARIA\Dane

Dodatkowe zabezpieczenia stabilności:
- pojedynczy formularz/upload jest ograniczony do 256 MB, aby błędny lub gigantyczny upload nie wyczerpał pamięci;
- przerwany lub błędny formularz daje czytelny komunikat i wpis do logu;
- jeżeli wcześniej używany katalog danych nagle nie ma bazy i nie ma poprawnego backupu, program NIE tworzy po cichu pustej bazy;
- przycisk „Zamknij program” na ekranie logowania jest obsługiwany również przez nowy wrapper Qt;
- skrót Windows kieruje bezpośrednio do `pythonw.exe` + Desktop, bez `cmd.exe`.
