RK KANCELARIA 0.15.0 — START NA WINDOWS
========================================

ZALECANY SPOSÓB:
1. Rozpakuj cały folder programu.
2. Jednorazowo uruchom: INSTALUJ_PELNA_WERSJE.bat
   - instalator Desktop tworzy własne środowisko programu w:
     %LOCALAPPDATA%\RK_KANCELARIA\Runtime\venv
   - OCR jest krokiem opcjonalnym.
3. Potem uruchamiaj: RK KANCELARIA DESKTOP.bat
4. Opcjonalnie utwórz skrót: UTWORZ_SKROT_NA_PULPICIE.bat

DANE:
%LOCALAPPDATA%\RK_KANCELARIA\Dane
Aktualizacja folderu programu nie kasuje bazy ani dokumentów.

DESKTOP:
Program nie uruchamia Edge ani Chrome jako osobnej przeglądarki.
Interfejs działa we własnym oknie PySide6 / Qt WebEngine.
Jeśli sterownik grafiki powoduje problemy, użyj:
RK KANCELARIA DESKTOP - TRYB BEZPIECZNY.bat

DIAGNOSTYKA:
SPRAWDZ_TRYB_DESKTOP.bat
Log Desktop: Dane\rk_kancelaria_desktop.log
Log błędów: Dane\rk_kancelaria_bledy.log
Log wolnych operacji (tylko >750 ms): Dane\rk_kancelaria_wolne_operacje.log

TRYB PRZEGLĄDARKOWY:
RK KANCELARIA - PRZEGLADARKA.bat pozostaje tylko jako awaryjny/serwerowy fallback.
