RK KANCELARIA 0.15.1 — HOTFIX STARTU DESKTOP
==============================================

Naprawiono regresję z 0.15.0, przez którą instalator szukał tylko Python 3.10-3.13.
Działająca wcześniej gałąź 0.14 używała ogólnego "py -3", dlatego komputer z Pythonem 3.14
mógł uruchamiać 0.14, a 0.15.0 zgłaszała błędnie brak zgodnego Pythona.

Zmiany 0.15.1:
- obsługa 64-bitowego Python 3.10, 3.11, 3.12, 3.13 i 3.14,
- przywrócony fallback "py -3",
- instalator najpierw potrafi wykorzystać istniejący Runtime RK KANCELARIA,
- PySide6 podniesione do >= 6.10.1 (obsługa Python 3.14),
- launcher Desktop nie sprawdza już wyłącznie obecności pythonw.exe;
  weryfikuje PySide6 / Qt WebEngine i podstawowe biblioteki,
- przy niepełnym/uszkodzonym Runtime uruchamiana jest automatyczna naprawa,
- ulepszona diagnostyka SPRAWDZ_TRYB_DESKTOP.bat,
- dane użytkownika i baza nie są usuwane ani resetowane przez ten hotfix.

URUCHOMIENIE:
1. Rozpakuj paczkę.
2. Uruchom INSTALUJ_TRYB_DESKTOP.bat (lub INSTALUJ_PELNA_WERSJE.bat, jeśli chcesz też OCR).
3. Uruchom RK KANCELARIA DESKTOP.bat.

Jeśli coś nadal nie działa, uruchom SPRAWDZ_TRYB_DESKTOP.bat — okno pozostanie otwarte i pokaże błąd.
